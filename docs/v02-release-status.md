## 使用与兼容性

通过`init --media --production-config config/production.example.yaml`显式启用v0.2；旧run继续使用其锁定标准，不原地升级。使用前读取[制作契约](contracts-v02.md)及[README](../README.md)。

合成样例可用以下命令复现，目标目录必须尚不存在：

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONPATH='.'
python tests/test_v02_pipeline.py --write-f01 ../video-flow-runs/v02-synthetic-F01
python -m video_flow verify-package ../video-flow-runs/v02-synthetic-F01/delivery
```

仓库只保存代码、可复用规范与合成测试。客户资料、实际制作图片、运行状态、凭据和本地测试日志保留在run目录中。
