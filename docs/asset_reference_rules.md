# V8 Asset Reference Rules

本文件定义资产、分镜板和视频模型之间的引用边界。核心原则是：分镜板是场景与静态视觉的唯一事实源，视频模型只接收完成运动所必需的最少参考。

## 命名

- 人物：稳定人物名或 `人物名_持续变体`。
- 场景：稳定具象场景名，仅服务于分镜板生成。
- 商品：自然商品名，资产 `business_role=advertised_product`。
- 普通剧情道具：`business_role=story_prop`。
- 布景装饰：`business_role=set_dressing`。
- 分镜板：`SB###_分镜板图`。
- 视频生成单元：`V###`。

## 视频模型素材白名单

每个 `V###` 只允许三类图片参考：

1. `source_boards` 声明并已审批的分镜板。
2. 对应镜头中实际出场的人物资产。
3. 对应镜头中的广告商品资产。

禁止传入：

- 场景资产图。
- 风格图、Moodboard。
- 布景装饰图。
- 特效参考图。
- 普通剧情道具图。
- 未出现在该 `V###` 中的人物或商品。

场景资产仍可生成并用于分镜板阶段，但 `video_prompt_manifest.json` 不得出现 `scene_assets`。普通道具不得进入 `product_assets`。

## 商品判定

`is_key_item=true` 只表示剧情重要，不表示广告商品。只有 `business_role=advertised_product` 的 Prop 才能：

- 设置 `generation_required=true` 并生成独立商品参考。
- 写入 `video_prompt_manifest.json.videos[].product_assets`。
- 打包到 `references/products/`。

## 分镜板承担的视觉内容

以下内容必须在分镜板生成时解决，视频提示词不得重新设计：

- 场景、构图和人物/商品初始位置。
- 布景、装饰、色彩、光线和材质。
- 烟、雨、粒子、光斑等静态特效造型。
- 广告文字的内容、位置和视觉样式。

视频提示词可以描述分镜中已有元素如何运动，但不能新增其造型、位置或参考图。

## 广告文字

- 广告文字必须写入 `storyboard.json.shots[].advertising_text`。
- 分镜包和分镜提示词必须逐字保留声明内容。
- 无声明文字时，分镜板禁止所有文字。
- 有声明文字时，只允许声明文字，禁止额外字幕、随机 Logo、乱码和水印。
- 禁止使用“尽量生成”“后期叠加”“后期替换”“预留修正区域”等回退方案。
- 分镜板审批必须提交文字核验凭证；内容不一致或存在额外文字时不得审批。

## 视频提示词

提示词素材区只允许：

```text
@SB001_分镜板图
@人物资产名
@商品资产名
```

画幅必须显式声明。项目未特别设置时使用 `16:9`。

含广告文字时，约束必须要求保持分镜板中既有文字内容、位置和样式不变，并禁止新增文字；不含广告文字时，使用无字幕、无 Logo、无水印约束。

## 机械检查

- `V###` 时长为 4–30 秒。
- `source_shots`、`source_boards` 和画幅与上游一致。
- `character_assets` 只包含出镜人物。
- `product_assets` 只包含 `advertised_product`。
- Manifest、提示词和最终包中均不存在场景或普通道具引用。
- 含文字分镜板拥有与其媒体 Revision 绑定的文字核验审批。
