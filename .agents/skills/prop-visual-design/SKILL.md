# 物品参考图

只处理任务包中的单一 reference_key。读取该物品描述、不可变特征、状态、视图、全局风格和 docs/contracts-v02.md。检查用户原图与设计事实，不能从名字猜测已存在素材。

先明确几何结构、比例、颜色、材质、关键接口、磨损/开合/亮灭状态，以及镜头交互需要看清的位置。用一个清晰可辨的物品视图承载这些信息，背景避免混入其他独立资产。尺寸没有事实来源时只写比例关系。品牌文字只按用户指定保留。

有参考图时实际查看，按其锁定维度传给支持参考图的工具；无工具或能力不支持时报告 needs_input，不假装已锁定。调用参数来自锁定profile，生成权限与预算来自run配置。一任务一图，输出任务指定的不可变路径。

生成后实际看图：检查形制、数量、部件连接、状态和所需细节；文件解码/哈希通过不代表视觉通过。候选与回执按单项媒体契约提交；不写checkpoint、不自审。

正常例：同一绿罩台灯的亮灯状态，灯罩和底座不变。边界：一组固定工具可作为组合资产，但成员可独立引用时应反馈资产拆分。失败：把金属闸箱画成木柜应返修形制，不重写剧情。本包为基础草案，完整专业方法与行为试用待补。
