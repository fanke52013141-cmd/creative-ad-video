# 基础规范

根据用户原始提示词整理，并修订内部冲突。本文件与入口、生产方法共同执行；入口列出的适配说明优先。原文存档在仓库资料区，不作为额外运行指令。

- 最终只输出中文提示词，不输出英文版本。
- 英文标签可以保留，但必须嵌入中文提示词中作为触发词，不单独输出 English Prompt。
- 不输出分析过程、不输出设计理由、不输出维度表、不输出确认清单。
- 不使用模型专属语法，例如 --ar、(keyword:1.5)、EasyNegative。
- 不使用真实艺术家姓名作为风格参考。
- 不保留未解压的模糊形容词，例如：酷、帅、可爱、高级、有故事感、有灵魂、独特、不要老套。
- 所有抽象形容词必须转化为可见的视觉参数，例如比例、形状、五官、服装、材质、颜色、姿态、道具、剪影。
- 两个提示词中的角色核心描述必须完全一致，只允许布局、视角、姿态和光照规格不同。
- 输出内容必须放在代码块中。

角色设计必须遵循以下原则：

1. 单一清晰概念
每个角色必须能用一句话概括核心概念。所有视觉选择都服务于这个概念。

2. 剪影可读性
角色在纯黑剪影状态下也应能被辨认。可通过比例、发型、服装分割或配饰建立辨识度；不强制夸张。可选标志性元素，例如特殊发型、不对称披风、夸张配饰、机械义肢、角、尾巴、巨大道具等。

3. 形状语言
使用基础形状建立角色气质：
- 圆形：柔和曲线、弧形轮廓和体积连接；人格含义由叙事定义
- 方形：直线块面、水平或垂直分割和稳定支撑；不强迫改变体型
- 三角形：尖角轮廓、收束方向和斜线节奏；不据此规定善恶

注意：这些性格词只作为内部判断，不得直接写入最终提示词，必须转化为具体视觉描述。

4. 有目的的夸张
只夸张最能表达角色身份和辨识度的部分，例如身体比例、五官、发型、武器、服装轮廓或标志性道具。
弱化不影响辨识度的碎纹理、重复装饰和缩略图中不可见的小细节。

5. 配色控制
以 60/30/10 配色层级作为可调整的起点：
- 60% 主色：角色视觉基调
- 30% 辅色：层次与对比
- 10% 点缀色：最容易被记住的视觉锚点

6. 表情可读性
角色面部结构应支持情绪变化，但基础辨识度不变。通过眉毛、眼睛、嘴角、眼神方向描述表情，不直接写“高冷”“腹黑”等抽象词。

7. 多角度一致性
角色必须在正面、侧面、背面和立绘中保持同一套比例、服装、颜色、道具和标志性元素。

构建角色时，内部必须遍历以下 7 个维度。最终输出时不要列维度标题，而是融合成自然语言提示词。

1. 角色身份与核心概念
- 性别、年龄段、种族或物种
- 职业、身份或社会角色
- 一句话核心概念
- 默认姿态和体态暗示

2. 体型与比例
- 头身比
- 体型倾向：纤细、匀称、壮硕、肥胖、瘦高、矮壮
- 主导形状语言：圆形、方形或三角形
- 次要形状语言
- 有目的的夸张点

3. 面部与发型
- 脸型、眼型、鼻型、嘴型、下颌线
- 默认表情，用具体肌肉和五官状态描述
- 发型剪影
- 发色、发质、发量、发长
- 面部标志：疤痕、胎记、纹身、眼罩、特殊瞳色、面具等

4. 服装设计
按照内层、中层、外层描述：
- 内层：贴身衣物、衬衫、紧身衣、T恤等
- 中层：夹克、制服、连衣裙、铠甲、主体服装等
- 外层：外套、披风、斗篷、背包、翅膀等

同时描述：
- 材质：棉布、皮革、金属、透明材质、织物垂坠、反光程度等
- 功能性：口袋、工具挂件、武器插槽、磨损痕迹
- 时代与文化参考：现代都市、未来科技、中世纪、东方古风、混搭等
- 鞋靴和配饰对剪影的影响

5. 配色方案
- 主色 60%
- 辅色 30%
- 点缀色 10%
- 配色逻辑：互补、类似、三角色、单色调
- 饱和度与明度对比

6. 标志性元素
- 剪影突破点
- 标志性道具
- 重复视觉母题
- 独特身体特征或装备结构

7. 风格与媒介
- 写实度
- 渲染方式：赛璐珞、厚涂、平涂、3D 渲染、水彩、PBR 材质等
- 线条风格：有描边、无描边、粗线条、细线条
- 只能用视觉特征描述风格，不使用真实艺术家姓名

角色转面参考图固定规格：

- 画面比例：21:9 超宽横版
- 布局：四个区域，从左到右依次为：
  1. 面部特写，占约 20% 宽度
  2. 正面全身，占约 26% 宽度
  3. 侧面全身，占约 27% 宽度
  4. 背面全身，占约 27% 宽度
- 各视图之间有清晰分隔
- 背景：纯白色
- 光照：平坦工作室均匀光，无戏剧性阴影
- 透视：正交或平面透视，无镜头畸变
- 姿态：自然站姿，非 T-pose，双臂自然下垂或微微离开身体，确保服装轮廓可见
- 用途：概念设计参考图

可保留以下英文标签；不把标签视为模型保证：
character reference sheet、character turnaround、front view、side view、back view、same character、consistent design、white background、concept art、full body。

单人全身立绘固定规格：

- 画面比例：2:3 竖版
- 布局：单一角色全身像，居中构图，头顶和脚底留适当边距
- 背景：纯白色
- 光照：柔和工作室三点布光，轻微阴影保留体积感但不遮挡细节
- 透视：约 5° 微微仰视，增强角色存在感
- 姿态：带有角色性格表达的自然站姿，可比转面参考图更动态，但不能遮挡关键设计细节
- 用途：角色展示和立绘资产

可保留以下英文标签；不把标签视为模型保证：
full body character illustration、single character、standing pose、white background、character design、high detail。
