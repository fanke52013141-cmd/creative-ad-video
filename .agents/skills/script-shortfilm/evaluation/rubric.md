# 评审锚点与独立评测规程

评审对象是当前 artifact 的明确 revision/hash，不能拿旧稿优点为新稿背书。评审者收到 brief 原文、候选、锁定 Skill 与验收要求；必要时收到事实源和制作条件。作者自检与独立评审分开。作者不得用本表给自己的候选签署通过，也不能因内置案例读起来顺畅就把整个 Skill 标为完成行为验证。

## 硬检查先行

task_id 必须对应任务，type 必须为 story，items 非空且 id 唯一。scene_goal、action 非空，duration_seconds 是有限正数，每个 item 都有 dialogue 数组。时长和与 brief.duration_seconds 差不超过零点五秒。输入所需字段、锁定哈希、输出路径与收据必须按运行时标准核对；样例占位哈希不是合格收据。

任一事实与来源冲突、明确禁用内容出现、必要字段缺失、把 needs_input 当成可提交候选、版本未批准或独立评审覆盖不完整，都阻止接纳。数字对上不代表创意合格，创意高分也不能覆盖这些阻塞项。无对白要求要检查旁白、屏幕文字与背景广播是否暗中承担语言解释，不能只看 dialogue 是否空。

## 六个软维度，零至四分

**行动与选择。** 零分是没有可辨认事件；一分是人物只被动接受结果，转折靠偶然或旁人通知；二分有行动但选项无代价，关键后果仍由外力完成；三分有合理的竞争选项、人物执行的决定与可见后果；四分是选择同时改变目标、关系或自我认知，且代价在结尾仍被诚实保留。四分不是更惨，也不是必须死亡，而是事件设计更精确。

**场景贡献与因果。** 零分无法复述顺序；一分大部分场景换序无损；二分有主要线索但存在重复功能或状态重置；三分每场有清楚贡献，删场会造成可指出的损失，前后状态继承；四分必要信息、情绪节奏与空间作用相互支持，删任何一处都会损失独特体验。观察式任务以其声明的感知组织原则评分，不强行寻找传统转折。

**主题与人物复杂度。** 零分主题与事件相矛盾且无意图；一分只有标语；二分能看见议题，但一方完全作为稻草人；三分相互冲突的生活逻辑有合理性，主题通过动作体现；四分观众可以对决定持不同态度，却能准确指出人物在保护和放弃什么。不同评审者是否同意作者立场，不作为评分标准。

**信息清晰与结尾。** 零分关键事实互相撤销；一分主要转折全靠片尾解释；二分可理解但出现不公平隐瞒或开放对象不清；三分已确定与未知的内容可区分，结尾回应了影片承诺；四分结尾使前面动作获得新的但不自相矛盾的含义，开放部分为观众保留思考。闭合结尾可以得四分，开放也不自动高分。

**可视表达与声音。** 零分主要内容无法转成可见可闻事件；一分抽象心理占据关键场景；二分有动作但依赖旁白或字幕解释已有画面；三分动作、物件和声音能让读者理解关系，语言承担独特工作；四分形式与人物视角相连，声音、沉默与物件轨迹既明确又有余地。无对白任务若只剩难解象征，不因无台词获得加分。

**时长与制作适配。** 零分根本违反已知条件；一分数字凑齐但事件明显不可容纳；二分主要可行，仍有需澄清的动作或资源压力；三分时间账本合理，节奏重点与资源条件相符，桌面估算限制已标明；四分经过与任务相适应的读演或预演，修订有实际证据，且重要选择获得足够时间。未做预演不得声称达到该维度的验证型四分。

## 证据怎样写

每个维度至少引用一个具体 item id 和字段，完整覆盖所有 item。可写“在 S004.action 中主角收回接车的手，把门挡放到对方脚边，选择从接管变为提供条件；S005.action 的邀请回应这一变化”。不可只写“人物立体、感染力强”。批评同样要定位：指出 S003.action 已交出钥匙，S005.action 又写从口袋掏出，要求修正状态。

若输出通用 review artifact，coverage 应精确等于候选全部 id，criteria 记录 name、score 和 evidence；issues 使用运行时的严重程度，并写 location、reason。任何高分都不能抵消 P0 或 P1 问题；pass 必须满足运行时分数与覆盖条件。此页不授权工作者生成自己的独立 review，也不替主代理修改接纳状态。

## 评测实施与偏差控制

前向测试只给待测工作者任务题、Skill 和必要素材，不给参考案例答案、作者自评或评分预测。评测者保留本锚点和预期行为，按实际产出判断。测试材料全部为合成，不引用真实客户秘密。共用文件系统不等于隔离，若需要防止工作者读评测答案，必须由环境实施访问边界，不能只凭提示声称隔离完成。

同一故事允许多种高质量答案。评测重点是约束遵守、动作证据和交接完整性，不能要求复现内置案例的雨伞、钥匙或收据。评审存在分歧时，先比对对事件的理解，再讨论价值判断；若连发生了什么都不一致，优先修清晰度。保存评测者身份、输入哈希、输出哈希、问题定位和修订差异，才有可复查的回归记录。

本轮包内的验证器只检查文件、引用、计数、JSON 与合成候选机械契约。它不模拟观众，不给审美打分，也不证明本 Skill 能在未知任务中稳定产出。行为用例均待独立执行；未来完成某一例时只更新那一例的记录，不把局部通过扩写为全部成熟。
