# 原创方法与决策

本页把有限篇幅叙事变成可以执行的判断。以下动作表、分支规则和检查方式由本包原创编写，并非任何编剧的逐字理论或官方课程。来源页只记录少量经过核验的启发命题。时间分配是创作估算，需要读演、分镜或动态预演验证。

## 一、先决定影片究竟承诺什么

短片不等于删短的长片。观众交出九十秒，通常只够进入一段异常情境、理解一个重要关系、看到一次有后果的举动。五分钟可以让一种策略失败，让关系暴露矛盾，再让人物换用另一种策略；这仍然不代表必须交代人物一生。先写影片结束时观众能回答的问题，例如“她有没有把自己承认的错误交出去”，而不是“影片讨论诚实、人性和成长”。前者为事件选择提供边界，后者容易变成任意素材都能装入的主题筐。

从 brief 中分别摘出传播目的、叙事形式、观看场景、时长与制作条件。公益主题并不自动等于广告；有品牌露出也不自动需要产品解决冲突。判断主驱动：如果撤去品牌，人物的困境和结局仍成立，可能是品牌支持的独立短片；若任务的胜负条件是证明功能、引导购买或记住利益点，则交回主代理安排广告主剧本。不要让“电影感”三个字抹掉实际传播目的。

生成一句可被反驳的故事承诺：“一名总替邻居收件的退休门卫，为送出无人认领的最后一封信，必须决定是否承认自己多年前的隐瞒。”这不是要求每部片有秘密，而是要求外部目标和内在代价可以相撞。若目前只有“一个老人很孤独”，继续追问他今天要完成哪件事，谁能阻止他，失败在画面上是什么；若创作目标本来就是观察孤独的一段时间，则选择观察式分支，不伪造激烈冲突。

## 二、人物由策略进入，由选择显形

给主角写三个不同层次。外部目标是在当前场景可做成或做不成的事情，如关上漏雨的窗；初始策略是他反复依赖的办法，如替别人做决定来获得安全；脆弱点是这种办法为何难以放弃，如一旦不管，就害怕被证明毫无用处。只把外部目标交给场景描述，把后两项用来设计对手、道具与行为。不要把后台分析全部写成旁白。

人物的选择至少有两个能成立的选项。若一边只是愚蠢、残忍或明显违规，另一边毫无代价，人物并没有被真正考验。写下选项各自保住什么、失去什么，再检查是否能通过动作体现。一个女孩可以保住哥哥留给她的旧雨伞，也可以把它拆成布条修好陌生人的轮椅雨罩；两种在乎都具体，放弃有形物件的代价也可见。不能仅写“她选择善良”，要写她把哪一根支撑抽出、把什么交给谁、之后谁承担雨水。

障碍应逼出新策略。第一回失败可证明原办法的局限，第二回失败若只是同样的门再关一次，只在消耗时长。改变信息、关系或代价：最初是不会开锁，后来发现锁内还有人拒绝开，最后明白强开会毁掉对方保存的证据。每次变化使人物下一步可做的事情不同。九十秒可只保留一次策略失效；五分钟可以容纳两到三次，但不要按次数机械扩写。

选择之后必须有后果。后果不必是惩罚，也不必立刻获奖，而是人物、他人或环境对动作作出回应。签名之后文件被收走；递出的钥匙被放回；剪断的绳子无法恢复原长。若主角说自己变了，随后世界与行为完全没有不同，主题仍停在宣称。也允许人物拒绝改变，但拒绝要留下代价，让观众看见他更清楚地维持原状。

## 三、行动与活动的区别

活动描述人在忙什么，行动描述人借此改变谁的处境。擦桌子可以只是生活质感，也可以是把对方留下的名字擦掉，或故意擦出一块空处等对方坐下。判定方法是把动词后补上“为了使谁怎样”。若补不出来，保留该活动必须给出节奏、观察或感官目的；不是所有活动都要升级为戏，但每个活动都要承担有限时长中的工作。

抽象心理改写遵循“证据、反应、再选择”。“他愧疚”可改为：他把错投的信塞回包底；听见收信人询问，手指停在拉链上；最后把未封口的信举到桌面。三个动作之间有空间供演员表演，观众不必被告知情绪名。避免用“眼神复杂”“百感交集”代替具体选择，也避免把每种情绪强制换成握拳、流泪、摔杯的固定表情库。

写动作时保持因果主体清楚。“杯子摔碎了”可用于突然发现，但若故事关乎责任，应写谁碰倒、谁看见、谁决定不捡。主动句帮助后续分镜识别事件，不能因此禁止偶然事件；偶然可打破平衡，但解决主要困境最好依赖人物已经建立的能力、关系或选择。结尾才出现的中奖消息往往把主角从故事里移走。

微动作不等于低强度。一个人把另一人的名字从申请表划掉，可能比追车更不可逆。检验强度应问：观众是否知道名字属于谁，划掉会损失什么，人物是否知道损失，动作是否发生在可被对方发现的情境里。若这些条件没有建立，单独放大笔尖只会显得故作深沉。镜头大小由分镜决定，剧本要先建立事件重量。

## 四、场景必要性与删场试验

为每个场景写一句“本场使什么变得不再一样”。可改变的对象包括目标进度、人物关系、观众对事实的判断、角色掌握的信息、将来选择的代价，以及观众对空间与时间的感受。改变不只等于新情节：长椅从可供两人坐到只剩一人的位置，也可能构成关系变化，但必须有明确的前后证据。

做一次删场试验：临时移走整场，列出下一场因此无法成立的动作、情绪或理解。若答案只有“气氛少一些”，继续问气氛是否承担结局必要的等待或落差；若承担，就说明少了它结局怎样被误读。若完全没有损失，把该场最好的一句对白、一个物件或一个意象迁到必要场景，再删除空壳。该试验用于逼近贡献，不是把每个呼吸都剪成信息点。

进入场景时，尽量让人物已经在做有目的的事情。不要默认从进门、寒暄、坐下开始，也不要机械禁止这些动作；一场关于是否被允许进入家庭的戏，门槛就是核心事件。写三个不同入口：从请求开始、从失败后开始、从对方先采取行动开始。比较哪个入口能让观众最快理解当下压力，同时留下必要的未知。

离开场景应落在变化完成或下一步被迫出现的地方。人物争论后互相解释完，再用旁白总结，会抹平观众参与推断的空间。试着停在一只手没有接住递来的物件、警报突然停下、或本该走的人重新坐下。出口不能只有漂亮姿态；下一场必须继承这个变化，不能又恢复到双方什么都不知道的初始状态。

场景合并有三种方式。把信息并入阻碍，例如在借钥匙时才得知房子已退租；把人物并入同一行为功能，但保留关系差异；把地点并入一条可连续完成的路线，让空间压力取代转场解释。合并后重做谁知道什么的表。原本分别对两人说过的话不能突然变成所有人共享的秘密，否则节省的时长会制造新的逻辑债。

## 五、主题从相互冲突的生活逻辑中长出

先把主题写成问题，再给双方各一条能维持生活的答案。例如“照顾别人是否意味着替他承担所有风险”；一方相信替他挡住一切才是爱，另一方相信保留尝试的机会才是尊重。两者各有现实理由，影片才有争论的空间。不要先给其中一方贴上落后、冷漠的标签，再用情节审判他；这种写法会让人物只是作者的传声筒。

把主题放进物件和规则。若主题关乎信任，选择一件可以交出去、也可以收回来的东西；若关乎记忆，选择一处正在失去原貌的空间。物件必须先具有日常用途，才能获得情感意义。一个始终被打光强调却没有人需要的红色盒子，不能只靠结尾打开就自动成为隐喻。道具的价值来自人物曾怎样使用、拒绝或保留它。

主题证据至少跨越两种动作。开始时她替父亲把扣子扣好，结尾时她把扣子留在他手里等他自己尝试；关系在同一件事上的变化比新增一句“尊重很重要”更有说服力。也可设计反向变化：人物开始愿意等待，最后因压力接过扣子，影片由此提出一种不安的观察。正向成长并非唯一合格结局，清楚呈现选择与代价才是本包要求。

不要把命题当成科学结论。一个角色得到原谅不能证明所有隐瞒都有益，一个善意导致失败也不意味着善意愚蠢。保持短片的范围：它讲这两个人在今天这个处境中的一次行动。若 brief 要求公共议题事实，事实的来源核验要独立完成；戏剧效果不能赋予虚构情境统计代表性。

## 六、时长由事件占用，而非文字页数担保

先做一个时间账本，分别估算观察建立、行动执行、对白、对方反应、必要沉默与转场。两句台词未必只花几秒，因为人物可能等待机器停转才敢说；一个“她爬上楼”也可能占二十秒或直接切去。每场标 duration_seconds，同时用 timing_note 说明估算基础。总秒数对上目标只是机械条件，不代表观众能在该速度理解事件。

九十秒优先保住一个清楚动作、一处代价和一个结果。开头越短，人物关系越需要通过共用物件或既成行为显示。五分钟可以给误解留时间，但新增场景要带来策略变化。若九十秒稿包含童年闪回、成年失恋、职场挫败和最终旅行，先选择当下最能承载主题的一件事，其他阶段移为后台材料，不能靠十秒蒙太奇声称都已讲清。

用读演检验对白，再用动作走演检验无声段落。没有读演条件时，标为桌面估算，列出最可能超时的动作，不声称完成真实播放测试。中文每秒字数不宜设成全球常量：争吵、耳语、方言、儿童和长者节奏不同。若任务包给出平台对白限制，引用该 profile 并执行；本包不把某个生成模型的秒数上限写成短片艺术规律。

压缩时先删重复意义，再删连接过程，最后才缩表演停顿。两次都表达人物害怕的反应可以保留最有选择压力的一次；取杯、倒水、放杯可在对白中并行，不必各占一个事件；而人物即将签名时那次犹豫若承载整个选择，就不能为凑整秒数直接砍掉。把节奏差别写进动作，而非在每场末尾加“节奏紧凑”。

## 七、无对白分支

无对白不等于无声音，也不等于角色不能交流。先确认禁止的是可辨认语言、旁白、字幕，还是全部人声。把允许的声音列清楚：门铃、机器回转、脚步、呼吸、远处广播都可能承担叙事，但若广播说出了关键事实，它实质上仍是语言解释。不能用手机聊天文字绕过“无对白”的创作目的，除非 brief 明确允许文字叙事。

建立信息通路：观众如何知道目标，如何发现阻力，如何理解选择。可以用反复尝试的动作形成规则，用空间阻隔体现关系，用可数的物件体现损失。先让人物尝试把三只杯子放进箱子，再让他不得不留下一只，比直接写“搬家意味着离别”更容易拍。观众不需要理解道具的全部身世，只需要知道此刻谁在乎它、为什么不能全保住。

做一次遮字试验，把对白、便条、显示屏文字全部遮掉，只读动作。如果关键转折消失，决定补行为证据或申请文字例外。不要把动作堆成猜谜：辨认目标本身不应占掉全片大半时长。再做一次去配乐试验，确认音乐撤掉以后仍能辨认事件；音乐可以放大感受，但不能替代缺失的因果或人物关系。

无对白中的误解要公平。观众先看到足以支持错误判断的真实片段，结尾补入另一个真实角度；不能把前面已经明确拍出的事实撤回。一个人偷偷拿走钥匙，后来显露是为归还失物，可以是重新理解；前面拍他烧掉钥匙，最后说钥匙一直没离开桌面，则是自相矛盾。动作信息同样需要版本与连续性检查。

## 八、开放结尾与观察式分支

开放结尾要区分三件事：主要动作是否发生，人物承担了什么，未来结果是否未知。可以关闭前两件而开放第三件，例如道歉信确实被交出、主角也放弃匿名，收信人是否原谅留在片外。若连信是否寄出都不给证据，仍然可以成立，但需要影片真正关注“能否放手那一刻”；不能用剪黑逃避作者没有设计好的关键选择。

写结尾时列“已经确定、允许争论、禁止误读”。已经确定：她把钥匙放到对方掌心；允许争论：他们会不会重新共同生活；禁止误读：钥匙是偷来的。若禁止误读需要额外说明，就在前文补最小证据，不能在片尾旁白补免责声明。给独立评审只看正文，请其复述三个集合，再比较是否为同一部片。

观察式或诗性短片可以没有传统目标、失败和成长，但要声明组织原则，例如声音从近到远、一个空间被不同的人轮流占据、日常动作逐次失去功能。对应的场景变化改为感知或关系变化，仍需说明顺序为何不可随意打乱。若任何画面换序都无损，影片可能只是素材集；若本来就是可变排列作品，则需由 brief 明确这种形式与验收方式。

开放不等于含糊到不能拍。把演员此刻实际做的动作、声音何时终止、画面停在哪个状态写清。作者可以拒绝解释动机的唯一答案，却不能把动作写成“也许她离开，也许没有”。若确需多版本，分别提交 A、B 两个完整候选并注明各自后果，由主代理选择，不能让下游替剧本作者解决核心事件。

## 九、交接与创作完整性

给下游传递的是当前锁定的场景原文、人物状态、物件状态和约束，不只是“这是关于和解的故事”。艺术指导需要知道杯子必须能装水还是只象征空位，分镜需要知道人物有没有看到门缝里的脚，声音设计需要知道哪次报警声是角色听见而观众也听见。清楚记录叙事必需条件，把可自由设计的部分留给对应专业。

写完后从结尾倒推一次：关键选择依赖的事实是否已出现，选择所用能力是否被建立，代价是否先让观众理解；再从开头顺推一次：每一场的退出状态是否成为下一场的进入条件。两种方向发现的缺陷不同，前者抓凭空救援，后者抓人物失忆。所有修复都定位到 item id 与字段，避免“再高级一点”这类无法执行的评语。
