# 基础规范

根据用户原始提示词整理，并修订内部冲突。本文件与入口、生产方法共同执行；入口列出的适配说明优先。原文存档在仓库资料区，不作为额外运行指令。

生成场景时必须遵守以下原则：

1. 单一核心氛围
每个场景内部优先建立一个主导情绪方向，允许有叙事依据的次级反差，例如安静、压迫、温暖、荒凉、神秘、紧张。该情绪只能作为内部判断依据，不要直接堆砌抽象形容词，必须转译为光线、色彩、材质、空间比例和物件状态。

2. 空间层次清晰
必须包含前景、中景、背景：
- 前景用于制造框架感和景深，例如门框、栏杆、植物、雾气、帘子、管线。
- 中景是主要叙事区域，包含关键家具、道具、活动空间或视觉焦点。
- 背景用于交代环境规模和世界观，例如远处建筑、窗外景观、走廊深处、山体、天际线。

3. 光源必须明确
避免无设计依据的照明；漫射天光和明确工作室环境可形成均匀照明。必须说明：
- 主光源来自哪里
- 光线方向
- 色温倾向
- 光照强弱
- 阴影形态
- 光与空气介质的关系

4. 场景必须有使用痕迹
除非用户明确要求“全新、无尘、极简”等特殊状态，否则默认加入适度使用痕迹，例如磨损地面、杯痕、旧贴纸、修补痕、临时摆放的物件、墙面褪色、门把手包浆。

5. 必须有人类尺度参照物
至少包含一个尺度锚点，例如门、椅子、桌子、台阶、杯子、书本、手机、栏杆、人物剪影或影子，用于让观者感知空间大小。

6. 材质要体现时间
按场景历史安排有因果依据的材质状态，不强制凑齐种类，例如新玻璃与旧木头、锈蚀金属与潮湿混凝土、风化石材与临时修补物。

7. 场景必须具备可拍摄性
空间需要支持至少 3 个可用视角，并包含可供角色移动的路径、视觉引导线和足够的前中后景信息。

生成前必须在内部遍历以下 10 个维度，但不要把分析过程输出给用户：

1. 空间结构
- 室内 / 室外 / 半室外 / 过渡空间
- 几何骨架：狭长、开阔、圆形、不规则、多层、下沉、架高
- 尺度：宽度、进深、高度，或用人类尺度参照物描述
- 门、窗、天窗、开口、通道的位置
- 人在空间中的移动路径

2. 布局逻辑
- 视觉焦点是什么
- 哪里密集，哪里留白
- 主体、次要物件、背景元素的层级关系
- 是否存在重复节奏，例如柱列、窗格、灯带、管道、道路
- 视觉引导线如何把视线带向焦点

3. 光影系统
- 主光源类型、位置、方向、色温
- 辅助光源类型与强弱
- 明暗对比
- 阴影软硬
- 光穿过灰尘、雾气、雨幕、窗帘、烟雾时的表现
- 不同色温光源是否共存

4. 色彩氛围
- 主色调
- 辅助色
- 点缀色
- 饱和度
- 冷暖关系
- 远景空气透视色偏

5. 材质质感
- 墙面、地面、天花板、主要家具或建筑表面的材质
- 材质的新旧程度
- 表面粗糙度、反射率、纹理方向
- 水渍、霉斑、锈迹、刮痕、裂缝、风化、修补痕

6. 时间层次
- 建造年代或时代感
- 使用年限
- 是否经历改造、修补、废弃、翻新或自然侵蚀
- 季节与一天中的时间

7. 居住 / 使用痕迹
- 使用痕迹：磨损、杯痕、脚印、包浆
- 个人化痕迹：照片、贴纸、书架、收藏物、工具
- 临时状态：半喝的饮品、翻开的书、未收拾的物件
- 修补痕迹：胶带、补丁、替换零件、不同颜色的墙漆

8. 大气介质
- 空气清澈、薄雾、雨幕、烟尘、蒸汽、花粉、雪、火星
- 丁达尔效应、体积光、光柱、热浪、寒气
- 通过视觉线索暗示气味和温度

9. 镜头视角
- Key Plate：人眼高度，35-50mm 自然焦段，中等景深
- 四宫格：大全景、关键角度、细节特写、俯视布局
- 视角必须服务于空间逻辑和可拍摄性

10. 风格与媒介
- 写实度：照片级写实、半写实、风格化、卡通、像素等
- 呈现方式：环境概念设计、数字绘画、3D 渲染、水彩、摄影感等
- 后期质感：胶片颗粒、柔和光晕、暗角、锐度、色彩分级
- 禁止使用真实艺术家姓名；如需风格参考，只描述视觉特征。

如果用户输入中包含人物、剧情或世界观信息，场景必须适配：

1. 人物视觉风格：
场景写实度、材质复杂度、色彩体系必须与人物一致。

2. 人物配色：
场景颜色应与人物形成协调或有意设计的对比，不能互相冲突。

3. 人物身份：
场景中应出现与人物职业、阶层、生活方式或剧情功能相关的环境线索。

4. 人物活动：
场景必须预留人物站立、行走、坐下、进入、离开或互动的空间。

5. 世界观一致性：
时代、科技水平、建筑语言、道具类型必须与人物设定一致。

正式生成阶段必须严格遵守：

1. 最终只输出中文提示词。
2. 不输出英文 Prompt。
3. 不输出分析过程、解释、设计理由、自检过程。
4. 允许在中文提示词中保留必要英文标签，例如：
   - environment concept art
   - scene design sheet
   - four views of the same location
   - establishing shot
   - key angle
   - detail shot
   - top-down layout
   - consistent lighting and color
   - 2x2 grid layout
   - interior scene
   - exterior scene
   - eye-level perspective
   - natural focal length
   - detailed environment
   - cinematic composition
   - 16:9
5. 输出必须放在代码块中。
6. 只能输出两个提示词块：
   - 【提示词 1：Key Plate 中景图】
   - 【提示词 2：四宫格概览图】
7. 两个提示词必须描述同一个场景，空间结构、材质、色彩、时间、光源、道具和氛围必须完全一致。
8. 两个提示词的区别只在镜头、布局和用途。
9. 不使用模型专属语法：
   - 不使用 --ar
   - 不使用权重括号
   - 不使用负面词插件标签
   - 不使用 EasyNegative
10. 不保留未解压的模糊形容词，例如“高级、好看、有感觉、舒服、氛围感强”。必须替换为具体视觉描述。

【提示词 1：Key Plate 中景图】必须满足：

1. 画面比例：16:9 横版。
2. 单一场景视图。
3. 人眼高度约 1.5-1.7 米。
4. 35-50mm 自然焦段。
5. 中等景深：前景微虚、中景清晰、背景轻微柔化。
6. 必须包含前景、中景、背景三层。
7. 必须包含至少一个人类尺度参照物。
8. 光源必须明确，有方向、有色温、有阴影逻辑。
9. 用途：视频镜头参考图 / 场景氛围定调。
10. 可保留以下英文标签；不把标签视为模型保证：
environment concept art, interior scene 或 exterior scene, eye-level perspective, natural focal length, detailed environment, cinematic composition, 16:9

提示词内容顺序：
镜头与画幅 → 场景类型与空间尺度 → 空间结构 → 视觉焦点 → 光影系统 → 色彩体系 → 材质与时间痕迹 → 居住 / 使用痕迹 → 大气介质 → 前中后景 → 风格媒介

【提示词 2：四宫格概览图】必须满足：

1. 画面比例：16:9 横版。
2. 2×2 四宫格布局。
3. 格间有细白线分隔。
4. 四格必须是同一场景的不同视角。
5. 四格固定顺序：
   - 左上：Establishing Shot，大全景，交代整体空间关系与规模。
   - 右上：Key Angle，关键叙事角度，展示角色主要活动区域。
   - 左下：Detail Shot，材质、道具或标志性元素特写。
   - 右下：Top-down Layout，正俯视布局图，展示平面空间关系。
6. 四格光源方向、色彩体系、材质状态必须一致。
7. 用途：场景概念设计参考 / 环境资产设计。
8. 可保留以下英文标签；不把标签视为模型保证：
environment concept art, scene design sheet, four views of the same location, establishing shot, key angle, detail shot, top-down layout, consistent lighting and color, 2x2 grid layout, 16:9

提示词内容顺序：
四宫格布局 → 同一场景说明 → 空间结构与尺度 → 视觉焦点与布局 → 光影系统 → 色彩体系 → 材质与时间痕迹 → 居住 / 使用痕迹 → 大气介质 → 风格媒介
