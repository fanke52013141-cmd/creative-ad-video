# 专家来源与方法边界

访问核对日期：2026年10月24日。优先使用作者、工作室、出版社和会议官方材料。研究归因与运行规则分开：下面“公开命题”是来源能支持的内容，“适配”是为本次 Skill 设计的操作方法。没有直接引语，也不复制长篇正文。

## 来源1：Harvey Smith / Matthias Worch

- 标题：[What Happened Here? Environmental Storytelling，GDC 2010](https://media.gdcvault.com/gdc10/slides/Smith_Harvey_WhatHappenedHereWeb_Notes.pdf)。
- 可访问范围：已读取官方84页讲义的可解析文本；重点核对第12、15、33、41—52页；未声称观看讲座视频。
- 公开命题：讲义讨论用环境线索关联事件、允许解释，并让局部事件与世界前提呼应。
- 本次适配条件：地点需要历史与使用状态时。
- 决策规则：让少量可关联线索支持一个合理事件。
- 操作与证据：写原因、痕迹、现状的内部卡。
- 验收：终稿只保留可见线索，解释不过度确定。
- 例外：纯抽象或全新场景不强加旧物。


## 来源2：Scott Robertson / Thomas Bertling

- 标题：[How To Draw，出版社介绍](https://designstudiopress.com/products/how-to-draw)。
- 可访问范围：已读取出版社产品简介；未读取全书或完整教程。
- 公开命题：公开介绍以透视网格与基础形体为复杂物件和环境的构造基础。
- 本次适配条件：需要多视角复用时。
- 决策规则：先固定空间拓扑，再安排视图。
- 操作与证据：记录开口、路径、固定设施和尺度。
- 验收：换视角不改变地点本体。
- 例外：概念空间不等于施工测量。


## 来源3：Scott Robertson / Thomas Bertling

- 标题：[How To Render，出版社介绍](https://designstudiopress.com/products/how-to-render)。
- 可访问范围：已读取出版社产品简介；未读取全书或声称复刻章节步骤。
- 公开命题：简介把光、影和反射作为材料表现的基础，区分照明与反射问题。
- 本次适配条件：需要材料可读时。
- 决策规则：分开光源、阴影与表面反射。
- 操作与证据：说明来源、方向、软硬和主要材料。
- 验收：受光关系与世界位置相符。
- 例外：风格化可简化物理但保留一致规则。


## 来源4：Marcos Mateu-Mestre

- 标题：[Framed Environment Design，出版社介绍](https://designstudiopress.com/products/framed-environment-design)。
- 可访问范围：已读取出版社简介，未读取全书或插图细节。
- 公开命题：简介强调环境应承担叙事作用，并与角色的行动共同形成故事。
- 本次适配条件：场景承接角色行动时。
- 决策规则：把活动区域当主设计对象。
- 操作与证据：验证入口到行动点的路径。
- 验收：装饰不堵主要动作空间。
- 例外：纯氛围图可采用最小活动提案。


## 冲突如何处理

专家方法不是权威投票。先看当前任务的输入、用户用途与已锁定的产物，再选适用的方法；不同方法解决不同问题时并用，互相冲突时写清选择条件。概念艺术的夸张不自动适合写实资产，游戏中的自由探索不自动适合电影的固定取景，厂商指南不自动适合别家模型。遇到来源不足的具体技巧，保留为本次提案并通过案例或实际生成验证，不伪造研究结论。

本包中的字数、格数、主运镜数量、默认比例和交接字段属于用户工作流约定或本次工程设计。它们没有被包装成专家普遍定律。运行时不需要每次重新搜索所有来源；只有用户要求最新模型能力、来源核验或新增专业方法时才补查相关一手材料。
