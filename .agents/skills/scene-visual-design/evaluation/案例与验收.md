# 场景案例与验收

下面记录作者已完成的桌面演练及可复跑条件。响应片段是文本样例，不是已经生成的图片。独立新上下文测试、四宫格实际结构与视觉连续性仍待验证；当前包为 draft。

## 典型任务：雨夜仍在营业的修鞋铺

输入：当代城市旧街，狭长修鞋铺，门在南侧，工作台靠东墙，北侧有小窗。夜间下雨，台灯提供主要暖光，门外有弱冷光。主要动作是店主从柜台后走到门边收回一双鞋。不需要人物入画，希望真实生活感。

作者演练响应：

【提示词1：Key Plate中景图】

```text
16:9横向场景主视图，从南侧入口向室内观察，人眼高度、自然透视，中等景深。狭长修鞋铺，东墙前为连续工作台，北侧墙面留一扇小窗，入口与工作台之间保留清楚通道。中景工作台上的暖色台灯照亮鞋楦、工具和一双待修皮鞋，北窗外为暗夜；南侧门外的微弱冷光在近处湿地面形成浅反射。暗木工作台边缘有反复触碰形成的光滑区，水泥地通道有局部磨损，门边鞋架上保留待收回的鞋。前景为门框与少量雨水，中景为工作区，背景为北窗和收纳架；墙面和工具细节服从主活动区，不塞满通道。写实环境概念设计，材料可辨，画面内无人，无新增霓虹灯。
```

【提示词2：四宫格概览图】

```text
16:9横版二乘二等大四宫格，以细白线分隔，展示同一间修鞋铺。共同结构：南侧入口、东墙工作台、北侧小窗，入口至工作台之间保留通道；夜间下雨，工作台暖灯为主，南侧门外弱冷光辅助，暗木台面、水泥地和工具状态一致。左上从入口看整体狭长空间；右上从西侧看东墙工作区与门口通道；左下特写工作台边缘的触碰磨光、鞋楦与修补工具；右下为取消屋顶后的正俯视布局，清楚显示门、工作台、小窗和通道。所有视图使用同一地点与同一时刻，不增加房间，不改变固定设施位置，画面内无人、无文字。
```

检查记录：两条提示词继承同一结构；活动路径没有被物件堵住；不要求人物入画仍有鞋架、门和工作台作为尺度；阴影按世界光源而非屏幕左右保持；雨水只影响近门区域，没有把整间店无理由淹湿。两条提示词未调用专属参数。文字层通过，实际四格数量、透视与北窗位置待看图。

## 边界任务：全新无尘室

输入：全新启用的洁净实验室，用户明确不要灰尘、旧物、磨损和生活杂物，主要用于人物将密封样本放入检测台。灯光均匀，不要戏剧性阴影。

作者演练决策：保留洁净与均匀照明，主光来源设为天花板大面积漫射灯面，工作区有明确操作台和通道。时间状态为新启用，不强制加入旧木、锈蚀金属和杯痕；材料可以是亚光白色面板、拉丝金属与透明观察窗，但不要求三种不同年龄。四宫格细节选择密封接口与操作台边缘，不选择虚构的污迹。

检查记录：没有把基础规范“使用痕迹”机械执行为脏乱；均匀照明具有来源，不被误判为禁用；材料差异仍清楚；主视图不裁掉操作空间。若输出出现废弃感、墙角霉斑或蒸汽光柱，则判失败，修对应场景分支，而不是给所有场景增加无尘限制。

## 失败任务：唯一通道互相冲突

输入：用户要求宽度很窄的封闭房间，两侧布满固定深柜，中间还要放大型工作台，并允许三人并肩奔跑；没有平面参考或可调整项。

作者演练响应：现有空间要求在通行与固定设施上冲突。请指定优先保留狭窄封闭感、中央大工作台，还是三人并行的行动空间；也可允许把工作台靠墙。状态 needs_input，不先输出看似完整的两条终稿。

检查记录：问题针对具体矛盾，不要求用户提供全部装修参数；没有默默扩大房间；没有删掉固定设施；不把概念判断说成建筑合规评审。用户若选择扩大空间，即可更新核心结构并继续生成。

## 触发与反例

“给我同一场景的主视图和四宫格”“设计可换机位的旧车站”“把未来实验室描述变成环境提示词”应触发。“估算真实房屋承重”“画人物三视图”“写整片色彩圣经”不应被此能力替代。用户只要求一张场景提示词时可按要求输出一张，不因默认双图增加无关交付。

## 回归任务

增加一个反向机位，核对北窗、东工作台与南入口仍在原世界位置；画面中的左右亮暗允许反转。把夜晚改为阴天，检查只有照明和窗外状态发生合理变化，不重建家具。把写实改成平面插画，检查材料表现简化但拓扑与行动区不变。把有人场景改无人，检查没有强制塞人物剪影。

## 验收的证据

文字层需要共同核心、两种视图用途和清楚的光源关系。图像层需要实际查看四格：开口和固定设施相符、没有重复角度代替布局、细节属于同一地点、主活动区可用、文字与水印符合要求。生成模型可能漏格或改结构，提示词检查不能证明它已完成。只有实际生成授权到位后才执行图像验证，记录模型版本、素材、图片和逐格偏差。
