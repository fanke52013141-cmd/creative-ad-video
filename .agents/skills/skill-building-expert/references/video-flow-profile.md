# Video Flow 专业 Skill 建设适配

仅用于用户要求的视频创作执行标准；不作为所有 Skill 的通用强制要求。

## 深度与结构

剧本、艺术指导、分镜等专业包的原创中文内容建设目标为 10,000–20,000 字，按正文、方法、案例、反例与评估说明合计；排除重复文本、原始来源全文、代码与机器 Schema。精确计数字段和方式应在项目配置里定义。通用路由/校验/导出工具 Skill 无需为字数凑背景。

建议分配：入口 1,000–2,000；方法/决策 4,000–6,000；原创案例 3,000–5,000；失败修复 1,500–3,000；评估与来源说明 1,000–2,000。范围可调整，总量须实际统计，不能冒称达标。

每个专业包至少覆盖：核心任务、适用/不适用、分支决策、端到端原创案例、相反案例、低质量修复、客观约束与主观质量评分锚点。文献数量不能替代方法质量；关键规则尽量有一手来源，创作者经验与平台建议分别标注。

## Skill 工厂

能力需求 → 研究任务 → 来源核验 → 方法卡 → 本专家编译 → 独立试用 → 修订 → 发布固定版本。

研究子 Agent 输出 evidence.json、methods.md、gaps.md；本专家读取这些证据和 I/O 要求，不读取整个客户项目历史。评估子 Agent 只拿测试题、Skill 与必要素材；预期答案由评测方保留。

标准的唯一可编辑 Skill 源在 .agents/skills/<id>/ 维护，skills/catalog.yaml 只做索引；若其他平台需要另一目录则自动投影或构建，禁止两套正文手工维护。

## 路由与验收

分离传播目的、叙事形式、渠道、时长、制作方式、视觉风格。按任务组合一个主剧本 Skill 和必要叠加约束，避免多个主写作者抢同一输出。

硬验收阻止事实冲突、缺关键字段、超限、未批准版本、证据覆盖缺失。软验收检查因果、可视化、人物选择、情绪、品牌关联、风格一致和镜头动机；引用具体 scene_id/shot_id。

子 Agent 缺材料时申请字段/资产，不浏览全项目弥补。任务包记录输入 revision/hash、Skill 版本、引用章节、输出边界、验收版本和时限。仅传最小必要输入不等于丢失角色状态、硬约束与前后镜头衔接。
