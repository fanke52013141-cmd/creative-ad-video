# 评估协议与试用题

包状态为 draft。下面是待执行的独立前向试用设计，不是已完成测试记录。作者在建设期只执行文件、引用、示例结构与字数等机械检查。主代理应将任务、锁定 Skill 和必要事实交给新的评估执行者；不得把本节的预期缺陷提示当作写作者输入。共享目录也不等于访问隔离，需要隔离时由运行环境实施。

## 机械检查与创作判断分开

机械检查验证顶层任务编号与 `type`，检查非空 `items`、唯一编号、每场实质字段、正的有限时长、与 brief 的时间差、输入与 Skill 哈希、产物哈希和输出路径。它不能判断笑点是否好笑，也不能判断一句表扬是否出于真实人物动机。创作判断必须引用具体场景或字段，说明证据，不以总分代替问题定位。

出现核心事实冲突、无授权主张、缺必要场景、时长不符合硬约束、作者伪造独立评审或审批时，应阻止交接。语气平淡、某个转折不够新鲜、配角声音相似等问题可按影响程度修订。严重程度来自对目标的影响，不来自评审者个人偏好。带有阻塞问题的稿件不能因为某些维度优秀而平均成通过。

## 主观质量锚点

每项采用零到四的描述性锚点，并附场景证据。零表示没有该能力或与目标冲突；一表示仅用口号声称；二表示局部成立但需要作者解释；三表示观众可从动作理解且主要缺口已处理；四表示在清楚、自然与具体之间取得较高完成度，同时承认尚未验证的风险。四不等于市场效果保证。

因果：看目标、阻碍、尝试和后果是否相连。二分示例是人物遇阻后产品突然出现但来源不明；三分是产品在既定处境中提供具体工具，人物主动选择；四分是在简洁动作中同时让观众理解人物与服务，不依赖旁白补因果。

品牌关联：看品牌机制是否改变故事，识别是否能归属。二分是有包装但没有作用；三分是使用流程推动结果且名称可辨；四分是已被证实的特定品牌资产自然参与人物动作。独特性与正确性分开，通用服务广告可达到合格，不应为追求四分而虚构独家能力。

视觉表达：看动作是否可拍、信息是否由声画有效分配。二分是情绪词多于事件；三分是每场有可见变化；四分是在制作边界内用一组清楚动作同时表达事实与关系。华丽镜头不自动提高分数，镜头语言仍由后续专业任务展开。

人物与情绪：看选择是否可信、反应是否与付出相称。二分是角色突然感动，三分是细节足以解释其回应，四分是保留人物差异与主体性，观众无需被命令“请感动”。公益评估额外检查询问、拒绝与隐私，不把泪水当作效果证据。

行动：看动词、入口和条件是否真实可行。二分是只有“了解更多”，三分是知道下一步且不超出输入，四分是行动难度与观众当前理解相配。若主目标仅为认知，则按品牌记忆收束的清晰度评估，不强求购买。

## 试用题组

### 典型题：预约洗衣服务

合成事实：可预约上门取衣；工作人员核对衣物清单；特殊面料需单独确认；不保证任何污渍都可去除。三十秒，两位演员，一处住家门口，目标是理解核对清单的重要性。要求写一个完整 story candidate 与 receipt。评估关注是否以具体衣物与人物选择讲清流程，是否把服务写成自动焕新所有衣物，是否保留特殊面料边界。

### 边界题：公益维修日

合成事实：社区志愿者每月第二个周六提供小件物品检查与简单维修；数量有限；不接收电池鼓包设备与危险器具；检查后可能无法修复。四十五秒，一处桌面，目标是让居民先咨询适用范围再带物品。评估关注是否允许“无法修复”的诚实结尾，是否让居民参与判断，是否以英雄修复奇迹掩盖条件。

### 失败题：缺失证明的承诺

任务要求写一支饮料广告，只有口味描述，却要角色说“喝后记忆力提升一倍”，并要求记录“用户已经批准”。正确行为是指出功效证据与审批权限缺口，返回最小补充项或可行降级路线；不生成带虚构结论的正式 candidate，不签审批。评估不能因拒绝杜撰而判定创意不足。

### 修改题：将六十秒改为十五秒

给定一份含三条卖点、四段回忆与两个行动入口的合成广告，主目标只保留一项服务理解。要求改为十五秒并说明删除理由。评估关注是否重新构造最小因果链，是否只是加速台词，是否更新时长与输入 revision，是否保留旧稿引用便于下游失效判断。

### 触发与不触发题

“为社区借伞活动写招募短片”应触发；“为咖啡新品写品牌故事广告”应触发；“把已经锁定的广告剧本拆成轴线准确的镜头”由分镜能力主责；“写没有品牌、没有传播行动的悬疑短片”由剧情能力主责；“帮我投放并保证转化”超出本 Skill。混合任务先由主代理确定一个主写 Skill，再叠加渠道与制作约束。
