# 原创端到端案例

以下品牌、人物、机构与服务都是合成训练设定。事实仅在案例内部成立，不可搬成客户主张；案例展示从输入到候选的推导，不代表经过受众研究、真实拍摄或投放验证。完整候选保持 `story/items` 结构，附加字段帮助下游理解创作选择。

## 案例一：咖啡服务广告《把话留给你》

### 训练输入与必要事实

虚构品牌“折角咖啡”，主目标是让办公楼通勤者理解提前选杯、到店核对订单再领取的服务方式。已给事实只有：指定门店支持小程序提前下单；订单含姓名与取杯码；店员核对后交付；饮品制作与到店时间有关，不承诺永远无等待。三十秒，竖屏信息流，两个演员，一处柜台与相邻等候区，不能出现真实手机品牌或真实支付数据。没有降价、咖啡因功效、公益捐赠或食品品质认证的证据。

受众假设是：有些人在赶往下一件事时，希望把有限注意力留给眼前的人。这是创作假设，不是研究结论。策略句为：当一位女儿想跟父亲说清一个小决定，却不断被点单细节打断时，提前选好饮品让她在取杯时继续那句话。故事承诺的是减少重复说明的流程，不是解决家庭关系。

### 路线比较与取舍

路线甲原本设计上班族对着电梯倒计时冲刺，柜台杯子像接力棒递来。它速度感强，但容易暗示保证准时，且把忙碌当作不可避免的价值。路线乙设计一连串复杂杯型要求被机械播报，最后手机一句话解决，笑点清楚，却会贬低顾客偏好，也可能要求界面中不存在的功能。路线丙把点单细节与家人对话并置，让流程占用更少说明，保留关系的细节。选择丙，因为人物目标与服务作用有直接联系，已知资源足以拍摄，且不需虚构品质与时效承诺。

初版梗概里，父亲一直沉默，女儿说“我决定换工作了”，最后父亲因收到咖啡而欣然同意。这个因果不可信：咖啡不应买来家人对重大决定的认可。修订把决定降为“周末一起走那条老路”，结尾也不强制达成一致；父亲主动追问路线，说明对话继续，而非产品完成家庭和解。

### 作者的检查证据与保留风险

四场时长为五、七、八、十秒，总计三十秒。这里完成的是预算加总；没有演员朗读与现场粗演，不能写成已验证能拍进三十秒。第二场最容易超时，因为含订单可读、名字确认与取杯码确认，正式试读若超限，应先缩短第一场对白，或减少不必要的界面停留，不删掉必要核对。

移除检验显示：若没有提前选择，父亲需要重新确认饮品，女儿难以立即继续路线话题；服务作用成立。但替换成其他预约品牌仍可拍出相似故事，差异化较弱，因此该稿适合服务理解，不能声称已经建立独特品牌资产。后续若有真实品牌称呼、杯套语言或门店习惯，可选择一项融入动作，不能凭空编“独家”机制。

静音观察的桌面判断是：观众能看到照片、订单核对与父女继续交流，但未必理解周末路线的情感含义；字幕保留服务主信息即可，不需要给每个表情配解释。声音则负责关系细节。若客户更重视直接转化，可用一项真实且简洁的流程提示替换部分聊天；若客户要品牌温情，保留八秒对话比再堆三项卖点更一致。

该候选的独立评审尚未执行。评审需特别判断：父亲是否被写成不懂技术的刻板形象；女儿是否自然地帮助确认而非替父亲做所有决定；服务是否被误读为保证即时出杯。所有判断都应定位场景编号，不能只给“很温暖”的总评。

## 案例二：社区公益广告《这把伞先问一句》

### 训练输入与传播任务

虚构社区活动“问一句借伞点”，目标是让居民理解下雨时可在社区服务站开放时段询问是否有可借雨伞，并鼓励归还干净可用的闲置伞。事实条件为：服务站周一至周六九点至十八点开放；雨伞数量有限；不收借用费；借用与归还由工作人员登记；不接受破损或尖端裸露的伞。四十五秒，一个服务站门口，三位演员，雨景可用室内外滴水与声音表现，不要求真实暴雨。

这不是“有伞的人拯救无伞的人”。故事主角是拿着折叠伞的年轻人，他想帮旁边提购物袋的邻居，但不知道怎样开口。邻居拥有自己的判断，先说明袋上已有防水罩，只是自己忘记带伞，准备等雨小一点。一次询问让帮助从猜测变成合适的动作，并把公共借伞点带入故事。主目标是理解服务与适当参与，不承诺消除所有雨天困难。

### 从误区到策略

最初的错误路线把老人拍成在雨中无助颤抖，主角冲出去把伞塞进她手里，围观群众鼓掌，片尾写“有爱就没有风雨”。它制造了高情绪，却抹去受助者选择，忽略服务开放条件，且把活动作用夸大为普遍拯救。修订把戏放在“问错了也愿意听”的瞬间：主角以为邻居需要护住车，其实邻居需要两手推车时更稳定的遮雨工具。

策略是：先听清具体需要，再把现有社区资源交到合适的人手里。品牌在此是活动名称与登记流程；组织机制必须可见，才能解释这把伞为什么能再次流转。片中不拍真实姓名、电话号码与家庭住址；登记动作只表现空白训练表上的编号与归还提示。

### 被弃用的路线与修订选择

早期路线让邻居推购物车，工作人员借出可固定在车把上的支架伞。它有明确的动作作用，却引入了输入没有确认的道具能力。作者不能把“活动确有适配支架伞”当作当然事实，也不能把需要测试的固定安全性推给演员临场解决。这条路线即使情绪自然、总时长正确，也应先被事实门禁拦住。

一个曾考虑的修订是：邻居说“两手推车，我先等一会儿”，工作人员确认站内有普通长柄伞，询问是否愿意让青年同行撑伞到雨棚连接处。邻居决定只走到相邻雨棚，自己继续等雨；青年同意陪这一小段。它降低了道具适配风险，但青年承担更多帮助，故事仍需解释彼此的距离与同意，且普通雨伞的作用有些被人物善意遮住。

最终候选取消推车，改为有防水罩的购物袋。青年误以为需要护住物品，邻居轻轻纠正，普通伞即可解决眼前需要。戏剧摩擦更轻，但人物的判断更清楚，已知事实足以支持。选择由事实与制作条件决定，不能为了保住原稿而让客户补造服务能力。

公益案例说明“完整”并不等于“已经通过”。完整候选有明确场景、时长、行动与待确认范围，评审才能准确判断服务信息、人物主体性及执行难度。若作者只写“大家相互帮助，很温暖”，风险既没有消失，也无法定位。当前稿修复了支架伞的无依据能力，仍需正式试读，确认十秒内能让观众看懂检查与登记，而不把流程压成一句旁白。

## 案例三：同一服务的十五秒压缩决策

若咖啡任务改为十五秒，不能把三十秒台词加速一倍。保留的最小链是：父亲看向订单确认自己那杯，女儿说“提前选好了”，店员核对取杯码，父亲接着问“周末从哪头走”，片尾给品牌与入口。删除旧街照片的来历，保留眼前对话被流程占用又继续的变化。建议预算为三、五、三、四秒，仍须实际试读。

若客户同时要求加入咖啡豆产区、三种杯型、门店环境、五折活动与父女情绪，这已不是语言精简能解决的问题。作者应列出目标冲突，提供以服务理解为主的十五秒版本与需要更长时长的备选结构，由主代理处理范围。不能把所有信息缩成滚动小字，假装观众已接收。

若渠道改为无声电梯屏，策略可以保留，表达必须改变。父亲口头说姓名的核对信息需以简洁界面和动作呈现，不能只删除声音。关系细节可减少，服务事实与行动可读性上升。这体现渠道叠加约束影响写法，但不必把主剧本 Skill 改成另一套能力。
