# 专家交接约定

用于主辅组合、多阶段 campaign 或多轮改稿。单句任务无需向用户展示此表；字段可用自然语言传递，无需构造不存在的工具调用参数。

## 输入

| 字段 | 内容与缺省处理 |
|---|---|
| task | 选方向 / 成品 / 改稿 / 比较 / campaign，以及数量与格式 |
| product | 名称、品类、真实功能；名称缺失可用明确占位，产品本身未知需澄清或得到虚构示范授权 |
| audience | 使用者/购买者/决策者、场景；未知时标工作假设 |
| objective | 本阶段主目标、次目标、期限与成功指标；无依据不填数值 KPI |
| constraints | 渠道、规格、语言、市场、预算口径（制作/媒体/总额）、制作资源、禁用项 |
| facts | 宣称、用户提供的证据、来源/日期、核实状态；缺证据不升级为可发布宣称 |
| assets | 已确认的品牌主张、视觉/声音/语言资产、必须保留项 |
| assignment | 主/辅角色、负责哪份物料或模块、方法选择理由 |
| assumptions | 工作假设、待确认项、会触发改道的条件 |

## 返回

1. 指定交付物：概念、口号、脚本、文案或机制，而不只是“专家将完成”。
2. 必要的依据：卖点与事实、品牌关联、结构为何适合本渠道。
3. 假设与缺口：哪些可立即使用，哪些需事实、授权、政策或用户意见确认。
4. 验证状态：文本自检结果 / 尚未执行的受众测试建议 / 已提供的真实数据，分别列明。
5. 如果不可完成：冲突点、保留目标的最小调整、已完成的可用部分。

## 多模块合并

总调度检查同一品牌是否出现不同价格、不同承诺、不同主张；主模块负责核心目标，辅模块只改指定部分。辅助专家的建议若需要改变已确定目标，先显式说明，不自动覆盖。所有规格以用户当前要求为准，后续反馈只更新受影响字段与物料。
