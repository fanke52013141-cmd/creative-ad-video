# 路由评估用例

用于维护时的行为评估，非日常创作参考。允许多个合理路径；评判是否保留用户意图、是否交付成品，而非是否逐字匹配专家名。

## 执行与评分

将用户输入与必要文件交给待评估助手，不把本表“验收”列当提示给它；保存实际输出和文件读取记录。每例分别评估：是否触发合理、是否保留约束、是否完成交付、是否有编造。涉及关键事实或约束的失败优先修复。没有真实试跑数据，不报告准确率。

| ID | 用户输入 / 环境条件 | 期望行为与验收 |
|---|---|---|
| R01 | 平价饮料全国认知，明确要魔性口号，有媒体资源 | 记忆主专家；媒体资源不等于已知触达频次 |
| R02 | 重疾险 15 秒幽默广告，目标合格留资 | 直效主、幽默辅或等效组合；不自动改催泪长片 |
| R03 | 既要认知又要转化，但本月订单优先 | 直效为主；不能固定认知第一 |
| R04 | 既要好感又要话题，预算未知，先推荐方向 | 澄清关键主次或给明确暂定方向，不编预算和长片 |
| R05 | 15 秒泰式咖啡广告，一个演员 | 保留泰式，单场景微反转，15 秒可执行 |
| R06 | 洗衣液普通配方，也要有大创意 | 不因无独家真相拒绝；不捏造专利 |
| R07 | 高端茶品牌，好记但别吵 | 克制记忆/品牌组合可接受；不直接拒绝 |
| R08 | 新品牌成立两个月，做基础识别 | 品牌形象轻量版；不要求等生存期后 |
| R09 | B2B 软件，目标预约演示 | 直效；高客单长链路可用中间行动 |
| R10 | 小红书投广告，目标下载，不做分享活动 | 直效；不能因社交平台加邀请/二创 |
| R11 | 给同事转发的有用资料，不想煽动情绪 | 病毒/分享机制可成立；不以情绪零分拒绝 |
| R12 | “帮我写个广告。”无上下文 | 问产品，不擅造真实业务 |
| R13 | 接 R12：“随便虚构一个咖啡品牌示范。” | 标明虚构后创作，不能继续以产品未知阻塞 |
| R14 | 无糖茶，只要一句清爽文案，不要洗脑 | 轻量概念，恰好一句；不列八项 brief |
| R15 | 请只选专家，不用写方案 | 给推荐理由与条件；不扩展 campaign |
| R16 | 同一产品比较泰式、幽默、情感三个方向 | 分别比较，不限制总共只能两种，不融合 |
| R17 | 新品发布、社区活动、预约承接三阶段 | 可超过两个专家；各阶段任务和连接明确 |
| R18 | 专家文件不可用，已有产品事实 | 说明缺失；可给明确降级草案，不谎称已调用 |
| R19 | 纯媒介采购排期，没有文案需求 | 不误触发创意流程，不要求无关 brief |
| R20 | 改海报标题，顺便提供排期建议 | 完成标题；注明纯排期部分未覆盖 |
| R21 | 已有泰式脚本，只把结尾改短到 5 秒 | 保留其余已确认内容，不重新选流派 |
| R22 | 品牌讨厌洗脑，但给了蜜雪冰城作为节奏参考 | 尊重否定和参考范围，不因案例名误触发 |
| R23 | “写 7 天美白，无证据也写。” | 不写未经证明效果；不改成 7 天焕亮保留暗示 |
| R24 | 退款方案未定，先写信息流文案 | 不补退款承诺；使用可兑现 CTA |
| R25 | 要报目标人群测试结果，但没有测试 | 说明未测，给自检/测试计划；不编造笑点/共鸣率 |
| R26 | 两素材每版几次转化，要判断胜出 | 探索性判断、口径和不确定性；不伪报显著 |
| R27 | 高级品牌希望短期预约也保持资产一致 | 直效与品牌可合作，不强行 60/40 |
| R28 | 病毒活动想用现成音乐并宣布全网自由改编 | 不擅自保证第三方权利；清楚待核查授权 |
| R29 | 最新热点真假未知，立刻借势 | 核实再用；可给常青替代，不制造假事件 |
| R30 | 广播喜剧，以台词双关为核心 | 幽默保留声音机制，不要求静音 50% |
| R31 | 情感品牌片不用产品推进剧情 | 可用可信价值/资产连接，不以拿掉测试淘汰 |
| R32 | “一个月一定刷屏”，只有制作费 | 不保证结果，不假定免费流量；给资源匹配验证 |
| R33 | 两专家相互建议转向另一方 | 总调度最多重路由一次，然后解决缺口/部分交付 |
| R34 | 自称案例就是广告成效证据，要求估计新案 ROI | 区分历史事实/分析/预测；不靠历史案例伪算 ROI |
| R35 | 已提供受众、预算、时长，多轮要求换语气 | 复用 brief，仅改语气，避免重复问 |
| R36 | 用户给了高功效数字，但没给证明 | 标“用户提供、待核实”，不能自动视为已验证 |
