# 路由边界与组合

仅在多个专家接近、用户要求组合或跨阶段规划时读取。本套件是工作分类：大创意是概念能力；记忆、泰式、情感、幽默是表达与叙事能力；病毒是传播机制；品牌形象是资产管理；直效是行动优化。它们会重叠，不是公认且互斥的八大流派。

## 相邻能力如何选

| 容易混淆 | 判断问题 | 处理 |
|---|---|---|
| 大创意 / 病毒 | 缺一个核心概念，还是缺分享/参与方式？ | 概念归大创意，参与归病毒；好内容不等于传播机制 |
| 泰式 / 情感 | 意义重释是剧情主发动机，还是情绪靠日常细节累积？ | 前者泰式，后者情感；都可含幽默、温暖和轻反转 |
| 泰式 / 幽默 | 用户明确要泰式叙事，还是只要笑点？ | 尊重明确泰式；一般喜剧反转不自动属于泰式 |
| 记忆 / 品牌形象 | 要易复述口号，还是一整套一致识别？ | 前者记忆，后者形象；声音、角色的重复可同时服务两者 |
| 直效 / 病毒 | 主验收是合格线索/订单，还是自愿分享/参与？ | 按主 KPI 路由；社交媒体上也可以做直效 |
| 直效 / 品牌形象 | 要当期行动，还是解决资产混乱？ | 按交付选择主模块，另一项可作约束；高端不排除 CTA |
| 大创意 / 品牌形象 | 单次传播概念，还是跨物料长期主线？ | 按用户交付范围决定主负责人 |

## 不可靠的捷径

- 低预算 ≠ 能靠创意免费破圈。先检查自有触点、分发资源与可制作形式，再建议小范围验证。
- 总预算大 ≠ 足以高频触达。需要媒体预算、人群规模、实际触达与频次分布；缺数据时不计算伪精确频次。
- 保险 ≠ 只能拍催泪片；B2B ≠ 不能有大创意；高端 ≠ 禁用重复；初创 ≠ 不需要品牌资产。
- 15 秒不是对泰式的整体禁令；但复杂人物与多层反转可能塞不下，应简化机制并验证可理解性。
- 切片、截图只是物料形式，未说明分享理由、品牌承接与参与路径时，不必额外调用病毒专家。

## 编排样式

- **单条幽默转化片**：直效负责利益、证据和 CTA；幽默负责表达。按观看路径分工，不按 70/30 篇幅切分。
- **品牌片的社交发行**：叙事专家完成主片；有独立参与设计需要时再由病毒设计机制与授权范围。
- **新品多阶段**：可由大创意定概念、品牌形象约束资产、直效承接预约。阶段并行或顺序由业务决定，不强制先洗脑再情感。
- **多风格比稿**：保持同一事实、受众、主目标与资源范围，分别展示选择，不把三种风格塞进一条片。

## 取舍与测量

每阶段确定主指标及必要约束指标：认知看正确品牌归属与记忆；好感看目标联想；传播看有效参与和品牌关联；转化看合格行动与成本；资产看识别与误归属。曝光、点击可做诊断，不能自动替代目标达成。

品牌建设与短期激活需要结合阶段、品类和资源分配；60/40 可用于讨论，但不是所有品牌每年必须遵守的预算纪律。依据：[IPA：Effectiveness in Context](https://ipa.co.uk/knowledge/effectiveness-research-analysis/les-binet-peter-field)（核对日期：2026-10-11）。
