# 广告剧本

## 目标与边界

把传播目的变成可见的选择与结果，交付下游能继续设计、评审能逐场定位的剧本候选。广告包含商业与公益传播，但不能把所有故事都改造成销售话术。品牌认知、产品理解、行为转变分别确定一个主目标。叙事形式、渠道、时长、制作方式和视觉风格作为不同维度保留，不从“竖屏”推断“带货”，也不从“公益”推断“煽情”。

本 Skill 只写 `type: story` 的候选，不接受自己的稿件，不写 review、approval、总 checkpoint，不更换已锁定的 Skill 版本。人物、品牌、场景、数据、功效和价格来自输入；允许原创情节，不能把原创假设伪装成客户事实。完整方法见 [方法库](references/methodology.md)，不需要每次加载全包。

## 输入与读取顺序

先读任务包、被锁定的上游产物与 [接口契约](references/artifact-contract.md)。核对 `task_id`、输入 revision/hash、选定 Skill 版本、输出目录、验收版本。主目标、传播对象与被允许陈述的事实是必要业务输入；缺失时返回 `needs_input` 和最小补充项。时长或渠道未指定但不改变任务性质时可写明工作假设；未知事实不能靠“常识”补齐。

常规新写读取方法库第一至第八节；情绪、幽默或公益分支再读对应节。修改差稿读取 [修复手册](references/repair-guide.md)；需要完整示范读取 [原创案例](references/original-cases.md)；检查外部方法归属读取 [证据与边界](references/sources.md)。评审与试用读取 [评估协议](evaluation/protocol.md)，作者只做自检证据，不给自己独立通过。

## 执行

1. 建立事实表：把任务事实、证据、创作假设、待核实项分开；确定一个观众状态变化和一个行动。事实冲突先报告，不让文采掩盖冲突。
2. 写策略句：具体谁，在什么处境，因为哪种阻力，需要理解或尝试什么。把品牌或公益机制写成真实作用，而非片尾装饰。
3. 机制预选（0.2.0 起）：按 [创意总监路由](references/creative-director/SKILL.md) 先诊断主目标与起效机制——大创意/记忆/泰式/情感/幽默/病毒/品牌资产/直效八选一为主、至多一个辅助，给出一句可检查的选择依据写进候选 strategy；相邻难分读 [边界与组合](references/creative-director/taxonomy.md)。约束（版位、预算、禁用项）优先于机制偏好，核心机制保留不了就说明替代，不静默改道。然后生成少量有区别的创意路线，用因果、证据、品牌关联和可制作性比较。选一条写作，不把不同路线拼成卖点清单。任务要求多方案时，各自保持完整。
4. 写因果梗概，再拆成分场。每场有目标、动作、变化与时长；场与场之间说明前场结果如何逼出后场选择。用可见动作承载信息，旁白只补画面无法有效表达的必要层次。
5. 分配品牌、产品证明、情绪与行动。品牌接触点不只靠标志；产品作用必须与证据相符。公益故事交代能执行的动作与服务条件，避免把受助者当作工具。
6. 做计时、朗读、静音理解与移除检验，逐项记录限制。按 [契约](references/artifact-contract.md) 写 candidate；附自检 receipt，说明执行过与待执行的检查。

## 输出与门禁

主产物必须有 `task_id`、`type: story`、非空 `items`；每个 item 有唯一 `id` 及 `scene_goal`、`action`、`duration`、`dialogue` 等实质字段。总时长与每场时长一致，事实性台词和画面均有证据引用或明确的待核实标志。场景编号供艺术指导、分镜与评审引用，不能用一段总结冒充分场。

机械自检关注可解析、字段、编号、时长、引用、路径；创作自检关注因果、人物选择、品牌必要性、视觉表达和行动可行性。两类结果分别记录。任何未经证实的核心宣传结论、无来源的真实用户评价、虚构折扣时限、超出硬约束的场面均不能以“创意需要”放行。

输入不足返回 `needs_input`；约束互相冲突返回冲突字段与可行改写；证据仅支撑部分表述则降级表述并标记剩余缺口。修订另写新 revision，不覆盖上游或既有已审版本。若独立评估尚未发生，交付状态保持 candidate，包状态保持 draft。
