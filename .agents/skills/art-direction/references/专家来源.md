# 专家来源与方法边界

访问核对日期：2026年10月24日。优先使用作者、工作室、出版社和会议官方材料。研究归因与运行规则分开：下面“公开命题”是来源能支持的内容，“适配”是为本次 Skill 设计的操作方法。没有直接引语，也不复制长篇正文。

## 来源1：Bruce Block

- 标题：[The Visual Story，出版社介绍与目录](https://www.routledge.com/The-Visual-Story-Creating-the-Visual-Structure-of-Film-TV-and-Digital-Media/Block/p/book/9781138014152)。
- 可访问范围：已核对搜索引擎返回的出版社介绍与目录；直接打开返回403，未读取全书或第九章全文。
- 公开命题：公开介绍列出空间、线条、形状、明暗、颜色、运动、节奏，并说明视觉结构与故事结构相关。
- 本次适配条件：全片需要视觉弧线时。
- 决策规则：先选少量主变量，再把变化绑到故事事件。
- 操作与证据：记录变量、触发事件和可见结果。
- 验收：移除变量后若叙事不变，降为可选。
- 例外：用户已锁风格时只调允许变量。


## 来源2：Lou Romano / MoMA

- 标题：[Colorscript. The Incredibles, 2004](https://www.moma.org/audio/playlist/192/2575)。
- 可访问范围：已读取展览音频文字稿，含设计师本人说明；未观看完整制作档案。
- 公开命题：色彩脚本用简化的颜色与形状组织段落情绪，并在制作时帮助参照前后场景。
- 本次适配条件：需要跨段落色彩控制时。
- 决策规则：先看段落关系，再细化材料颜色。
- 操作与证据：列恒定色、变化色及前后承接。
- 验收：转折有事件依据，不能全靠颜色标签。
- 例外：黑白项目改用明暗关系。


## 来源3：Walt Disney Animation Studios

- 标题：[Visual Development](https://www.disneyanimation.com/process/visual-development/)。
- 可访问范围：已读取工作室公开流程页；未把图像未见细节当作证据。
- 公开命题：视觉开发以剧本与导演愿景为依据，用角色、世界、颜色、设计与构图强化主题。
- 本次适配条件：角色与世界需要统一时。
- 决策规则：以已知主题确定共同视觉边界。
- 操作与证据：给角色、场景和摄影分别交接规则。
- 验收：同一规则能支持不同地点。
- 例外：不代替下游制作具体资产。


## 冲突如何处理

专家方法不是权威投票。先看当前任务的输入、用户用途与已锁定的产物，再选适用的方法；不同方法解决不同问题时并用，互相冲突时写清选择条件。概念艺术的夸张不自动适合写实资产，游戏中的自由探索不自动适合电影的固定取景，厂商指南不自动适合别家模型。遇到来源不足的具体技巧，保留为本次提案并通过案例或实际生成验证，不伪造研究结论。

本包中的字数、格数、主运镜数量、默认比例和交接字段属于用户工作流约定或本次工程设计。它们没有被包装成专家普遍定律。运行时不需要每次重新搜索所有来源；只有用户要求最新模型能力、来源核验或新增专业方法时才补查相关一手材料。
